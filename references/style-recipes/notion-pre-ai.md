# notion-pre-ai — Notion-Inspired Early Editorial Warmth

Illustrative cues, not an official brand specification. Supplied references and accessibility needs take precedence.

**Context**: Modern Tool / Builder SaaS. Collaborative software and approachable, text-led productivity experiences.
**Reference points**: Notion marketing and product material from approximately 2017–2022; this is a historical inspiration, not a current specification.

## Starting palette and type

- White `#FFFFFF`; cream `#F7F6F3`; ink `#37352F`; secondary text `#787774`; border `#E9E9E7`.
- Soft accents: mint `#E4F4F1`, peach `#FFEDD5`, rose `#FCE7F3`, and sand `#FEF3C7`.
- A friendly serif such as GT Sectra, Sentinel, or Source Serif can support editorial headings. Inter, Söhne, or the project family can support body and interface text.
- Body text around 16px and line height around 1.6 are useful starting points.

## Composition cues

- Spacing example: 4 / 8 / 16 / 24 / 40 / 64; radius examples 4 / 8 / 16px.
- Quiet elevation, for example `0 2px 8px rgba(15,15,15,0.04)`, can distinguish surfaces without dominating text.
- Page icons or emoji can identify meaningful content types. Use them where they help recognition and match the product's tone.
- Block relationships, readable outlines, soft category labels, and conversational copy can make information feel approachable.
- Line illustrations and restrained state transitions can add warmth without interrupting work.

## Tradeoffs

Neither serif headings nor a light theme are requirements. Follow supplied product conventions, including dark mode or a different icon system. Dense workflows may need stronger grouping and more compact spacing; an enterprise audience can still benefit from approachable language.
