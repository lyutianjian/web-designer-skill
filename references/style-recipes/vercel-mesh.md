# vercel-mesh — Vercel-Inspired Contrast and Atmosphere

Illustrative cues, not an official brand specification. Supplied references and accessibility needs take precedence.

**Context**: Modern Tool / Builder SaaS. Technical platforms and product stories combining precise UI with atmospheric color.
**Reference points**: Vercel, Next.js, and related product marketing from the intended period.

## Starting palette and type

- Black `#000000`; surfaces `#0A0A0A` and `#111111`; border `#1F1F1F`.
- Primary text `#EDEDED`; secondary `#888888`; white `#FFFFFF` can provide a strong action contrast.
- Gradient examples: blue `#0070F3`, magenta `#FF0080`, and orange `#F5A623`, softened or saturated according to the imagery and message.
- Geist Sans and Geist Mono are useful starting fonts; Inter Tight or the existing project family may serve the same layout.

## Composition cues

- Spacing example: 4 / 8 / 16 / 24 / 40 / 64 / 96 / 128; radius examples 8 / 12 / 16px.
- Concentrate atmospheric color around a meaningful focal point; quieter surfaces can keep interface content legible.
- Fine rules, clear type hierarchy, and code or log material can establish a technical character when that content is relevant.
- Use authentic product output or explicitly labeled examples for terminal and deployment views.
- Ease-out interaction feedback and subtle ambient movement can complement the composition; static color fields may be sufficient.

## Tradeoffs

Gradient count, button color, and glow are compositional choices rather than fixed restrictions. Keep the primary action distinct and avoid letting atmospheric layers obscure controls or text. A warmer audience may need different imagery or tone while retaining the same precision.
