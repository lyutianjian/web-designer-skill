# vignelli-swiss-helvetica — Vignelli / Swiss-Inspired Order

Illustrative cues, not an official brand specification. Supplied references and accessibility needs take precedence.

**Context**: Information Architecture. Wayfinding, institutional identity, schedules, and structured information.
**Reference points**: Vignelli's 1972 New York subway map, Knoll catalogues, and The Vignelli Canon.

## Starting palette and type

- Black `#000000` and white `#FFFFFF`; supporting gray `#8A8A8A`.
- Accent examples: red `#E2231A`, yellow `#F5C518`, blue `#0033A0`, or orange `#FF6F00`. Assign colors to meaningful roles.
- Helvetica or Helvetica Now can establish the reference; a suitable project font can retain the same organizational approach.
- Example type scale: 72 / 48 / 32 / 24 / 16 / 12. Use size, weight, and spacing to express hierarchy at the actual viewport.

## Composition cues

- An 8px spacing rhythm and column grid are useful starting structures; align related information without forcing every component into the same geometry.
- Flat surfaces, crisp rules, and square edges can evoke signage.
- Bold color bars can label genuine sections. Keep text contrast sufficient on each bar.
- Tabular layouts and aligned figures support schedules and lists. A readable text measure around 60–70 characters can suit longer copy.
- Numbering is useful when it represents actual sections or a sequence.

## Tradeoffs

Order does not require banning serif text, italics, warmth, or motion. Use the grid to improve comprehension, and adapt the voice to the audience. An editorial story may need more varied pacing than a timetable even when both share the same visual vocabulary.
