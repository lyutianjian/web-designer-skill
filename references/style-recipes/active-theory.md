# active-theory — Active Theory-Inspired Cinematic Interaction

Illustrative cues, not an official brand specification. Supplied references and accessibility needs take precedence.

**Context**: Motion / Experimental. Campaigns, entertainment, and product moments where spatial interaction contributes to the message.
**Reference points**: Active Theory's portfolio and the specific project the user references.

## Starting palette and type

- Derive a dramatic accent from the campaign or product, supported by dark grounds and legible foreground text.
- Tinted neutrals can connect interface surfaces to the scene's lighting; neutral gray is also appropriate when it preserves clarity.
- Display options include a campaign-specific face, Druk, Editorial New, or ABC Diatype. Choose body type and contrast for text over imagery.
- Palette and typography are project-dependent; the reference is primarily about spatial composition and interaction.

## Composition cues

- A large scene can establish the experience, with interface elements placed where they remain reachable and legible.
- Use camera movement, material response, or particles when they reveal something meaningful. WebGL is one possible implementation, not a requirement.
- Scene lighting can establish depth; supporting interface surfaces should remain clearly differentiated.
- Build a coherent attention arc around the main message. Repeated effects should support rather than compete with that arc.
- If sound contributes, provide usable controls and retain the experience without audio.

## Tradeoffs

Match scene complexity to the target devices and performance budget, rather than a fixed production timeline. Provide a reduced-motion path that preserves the message and actions. A simpler interactive scene or static composition can retain useful cinematic cues when heavy rendering is unnecessary.
